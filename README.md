# Cine Forge 产品线框图

本项目是 **AI 内容工业化平台** 的产品线框图与原型说明资料库，不是可直接部署的生产代码仓库。

仓库中的文档和原型用于说明产品定位、核心流程、页面结构、关键交互和第一阶段研发范围，方便产品评审、老板汇报、研发拆解和后续 UI/前端实现对齐。

## 项目定位

Cine Forge 面向小说、剧本、短剧和视频内容生产场景，目标是把从文本输入到分析、剧本化、资产卡、分镜、镜头生成、审核、后期预览与导出的流程整理成一套可被 AI 辅助执行的内容生产工作台。

当前仓库重点表达的是：

- 产品要解决什么业务问题
- 第一阶段应该覆盖哪些核心闭环
- 用户在系统中的主要工作流
- 每个页面承载什么信息和操作
- AI 生成、人工确认、版本沉淀之间如何协作
- 后续研发团队可以如何拆分页面、接口、数据对象和任务

## 使用说明

本仓库当前不要求安装依赖或启动服务。查看线框图时，可以直接用浏览器打开：

```text
docs/ui-mockups/ai-content-platform-ui-board.html
```

如果浏览器限制本地文件访问，也可以在仓库根目录启动一个简单静态服务后访问 HTML 文件。

## 注意事项

- 本项目当前主要是产品线框图、产品文档和技术拆解资料。
- `docs/ui-mockups/` 中的 HTML 和图片是产品原型资产，不代表最终前端工程结构。
- 后续如果进入真实研发阶段，应基于 PRD、页面结构、API 文档和数据设计另行建立前后端工程。
- 文档与原型可能会随着产品讨论持续更新，研发前应以最新的页面结构和 UI mockup 为准。
