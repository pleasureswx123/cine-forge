# AI 内容工业化平台｜产品原型页面结构

> 适用范围：第一阶段核心闭环原型。  
> 原型目标：让产品、设计、研发、老板能清楚看到“用户如何从小说文本一路生产到视频片段和成片预览”。  
> 建议工具：Figma / Axure / 墨刀 / MasterGo。  

---

## 1. 原型设计目标

第一阶段原型不追求覆盖完整大平台，而是重点表达一条可落地的生产闭环：

```text
项目创建
  ↓
小说文本输入
  ↓
AI 小说分析
  ↓
剧本化改写
  ↓
角色卡 / 场景卡 / 风格卡
  ↓
AI Storyboard
  ↓
镜头级生成任务
  ↓
关键帧 / 视频片段审核
  ↓
简单成片预览
  ↓
项目资产沉淀
```

原型重点展示：

1. 用户从哪里开始。
2. 每一步 AI 生成什么。
3. 人工在哪里确认、修改、重生成。
4. 资产如何被后续环节复用。
5. 镜头如何进入图像/视频生成任务。
6. 项目最终如何形成预览和资产库。

### 5.2 项目生产工作台布局

```text
┌──────────────────────────────────────────────────────┐
│ 项目名称 / 项目状态 / 当前阶段 / 下一步动作 / 操作按钮  │
├──────────────────────────────────────────────────────┤
│ 横向生产流程 Step：小说 / 分析 / 剧本 / 资产 / 分镜 / 生成 / 确认 / 预览 │
├──────────────────────────────────────┬───────────────┤
│ 当前节点主工作区                       │ 项目上下文面板 │
│ 文本、表单、卡片、分镜、视频预览、版本对比 │ 当前产出       │
│                                      │ 待确认事项     │
│                                      │ 下一步建议     │
└──────────────────────────────────────┴───────────────┘
```

目录树不是所有页面无脑出现。项目概览只展示全项目状态和下一步动作；小说输入、分析页以源内容和分析模块为主；从剧本化改写开始，主工作区左侧才进入“集 → 场”的目录树；从 AI Storyboard 开始，目录树进一步展开到“集 → 场 → 镜头 / 分镜 / 任务”。

### 左侧目录树规范

| 页面 | 左侧目录树层级 | 叶子节点 |
|---|---|---|
| 小说输入 | 全小说 / 章节或梗概 / 镜头待生成 | 章节、梗概段落 |
| AI 小说分析 | 全小说 / 分析模块 / 镜头待生成 | 故事梗概、人物关系、场景列表等分析模块 |
| 剧本化改写 | 集 / 场 | 第 N 场剧本 |
| 资产卡管理 | 集 / 场 / 关联资产 | 当前场或镜头引用的角色、场景、道具、风格、声音资产 |
| AI Storyboard | 集 / 场 / 分镜或镜头卡 | 分镜 01 / SH-001 |
| 镜头生成任务 | 集 / 场 / 镜头任务 | SH-001 关键帧、视频候选、配音、字幕任务 |
| 镜头成片确认 | 集 / 场 / 正式镜头 | SH-001 正式视频 |
| 后期预览与导出 | 集 / 场 / 已确认正式镜头 | 时间线片段 |

## 6. 页面 1：工作台首页

### 页面目标

让管理者和项目成员快速看到平台整体生产状态。

### 页面模块

1. 数据概览卡片：项目总数、进行中项目、待审核任务、今日生成任务、模型成本。
2. 最近项目：项目名称、类型、状态、负责人、更新时间、进度。
3. 我的待办：待确认剧本、待审核资产卡、待审核视频片段。
4. 任务状态：排队中、生成中、失败、已完成。
5. 快捷入口：创建项目、导入小说、查看任务中心。

### 关键操作

- 创建项目
- 进入项目工作台
- 查看待审核任务
- 查看失败任务

## 9. 页面 4：项目概览

### 页面目标

展示单个项目的生产状态、当前所在节点和下一步动作，引导创作者进入项目目前应该推进的生产节点。

### 页面模块
1. 顶部生产流程 Step：小说、分析、剧本、资产、分镜、生成、确认、预览。
2. 下一步行动卡：显示当前阻塞点、推荐动作和明确入口，例如“进入小说输入”。
3. 项目生产结构摘要：目标形态、预计集数、当前是否已拆场、镜头目录是否已生成。
4. 节点状态地图：已完成、待输入、未开始、等待上游。
5. AI 节点建议：说明为什么要进入当前节点，以及完成后会自动推进到哪里。

项目概览不展示“集 → 场 → 镜头”目录树。只有当剧本化改写页生成分集分场后，后续页面才使用左侧目录树承载导航。

## 10. 页面 5：小说输入

### 页面目标

引导创作者选择内容输入方式，录入或上传原始故事，并整理为后续 AI 小说分析可读取的结构化源内容。

### 页面布局
```text
顶部：内容来源三选一（粘贴小说正文 / 上传小说文件 / 输入故事梗概）
节点内流程：上传/录入 → 解析内容 → 确认源内容
左侧：源内容目录（内容来源 / 解析后章节或故事结构 / 待处理问题 / 源内容版本）
中间：当前步骤的输入区、解析进度、解析后源内容预览或分析发起说明
底部：当前状态摘要 / 主操作按钮
```

### 功能模块
1. 内容来源选择：三种方式互斥，任选一种即可开始，默认推荐粘贴小说正文。
2. 上传/录入：支持粘贴正文、上传 TXT / DOCX / Markdown、输入故事梗概。
3. 左侧源内容目录：在上传前显示“等待录入/上传”；解析后显示章节、梗概结构和待处理问题。
4. 解析内容：系统识别章节、抽取正文、检查乱码/丢段，或将梗概扩展为故事结构。
5. 确认源内容：左侧展示章节/结构列表，中间展示当前章节正文预览或故事结构，右侧展示确认清单，并允许修正。
6. 进入 AI 小说分析：确认源内容版本后跳转到 AI 小说分析页面，由该页面开始分析任务并展示结果。

### 交互流程

1. 创作者先在顶部选择一种内容来源，三种方式互斥。
2. 选择后进入第 1 步上传/录入：粘贴正文、上传文件或输入故事梗概；此时内容可以为空，页面只负责输入。
3. 点击主按钮进入第 2 步解析内容：系统处理上传/粘贴/梗概，生成可检查的源内容结构。
4. 解析完成进入第 3 步确认源内容：创作者必须看到解析后的章节、正文片段、异常提示或故事结构草案。
5. 如果解析结果有问题，创作者在确认源内容阶段修正；如果没问题，确认该版本作为 AI 分析输入。
6. 点击确认后跳转到 AI 小说分析页面；小说输入页不展示 AI 分析结果。

### 上传文件示例流程

1. 上传/录入：创作者选择 DOCX 文件，页面显示文件选择状态，不显示解析结果。
2. 解析内容：系统抽取正文、识别章节、检查乱码和丢段。
3. 确认源内容：页面展示解析后的章节列表、正文预览、异常章节；创作者可以修正标题、拆分/合并章节。
4. 进入 AI 小说分析：确认源内容版本后，系统跳转到 AI 小说分析页面开始分析。

### 确认解析呈现内容

1. 确认解析只确认源内容解析结果，不确认人物、场景、剧情结构等 AI 小说分析结果。
2. 粘贴小说正文：系统给出“可以继续/需处理”的结论，列出章节数量、正文质量和丢段检查。
3. 上传小说文件：系统高亮必须处理的问题，例如标题缺失、乱码、丢段，并给出修正入口。
4. 输入故事梗概：系统展示故事方向、章节草案和可调整项，让创作者判断是否符合创作意图。
5. 确认源内容界面结构：左侧章节/结构列表，中间当前章节正文预览和可编辑项，右侧确认清单，底部按钮为“确认源内容，进入 AI 小说分析”。

### 操作按钮
- 保存小说内容
- 上传小说文件
- 确认源内容，进入 AI 小说分析

## 11. 统一 AI 修改交互规范

### 适用页面

AI 小说分析、剧本化改写、资产卡管理等所有需要创作者修改 AI 结果的页面，都采用“AI 修改当前对象”模式。

### 按钮作用域规范

所有生产页面的按钮按影响范围分为三层，不混放：

| 操作层级 | 放置区域 | 影响范围 | 示例 |
|---|---|---|---|
| 全局操作 | 页面顶部右侧 | 整个项目、整部小说、当前生产节点的全部产物 | 保存版本、重新生成全部、上传/管理参考素材、进入下一步 |
| 分组/类型操作 | 左侧分组或中间列表标题区 | 当前分类、当前场、当前模块、当前任务组 | 新增角色卡、从剧本补提角色、批量确认当前类型 |
| 单对象操作 | 右侧详情面板 | 当前选中的一张卡、一个镜头、一条任务、一个模块 | 编辑本卡信息、保存本卡信息、重生成当前视觉资产、删除本卡、标记通过 |

当没有选中具体对象时，右侧详情区只展示“请先选择”的引导态，单对象操作按钮禁用或隐藏。新增对象时先把空白草案插入中间列表，创作者再点击该草案进入详情填写和生成。

### 核心页面落位示例

| 页面 | 全局操作 | 分组/类型操作 | 单对象操作 |
|---|---|---|---|
| AI 小说分析 | 重新分析全部模块、保存分析版本、确认分析进入剧本 | 选择分析模块 | 编辑当前模块、保存当前模块、AI 调整当前模块、标记本模块通过 |
| 剧本化改写 | 重新生成全部剧本、保存剧本版本、确认剧本进入资产 | 选择当前集 / 当前场 | 编辑本场剧本、保存本场剧本、AI 改写当前场、标记本场通过 |
| 资产卡管理 | 重新提取全部资产、管理参考素材、保存资产版本、确认资产进入分镜 | 新增当前类型卡、从剧本补提当前类型 | 编辑本卡信息、保存本卡信息、重生成当前视觉资产、删除本卡、标记通过 |
| AI Storyboard | 重新拆分全部分镜、保存分镜版本、确认分镜进入生成 | 新增镜头卡、AI 重新拆分当前场、确认当前场进入生成、切换视图 | 编辑故事板提示词、重生成故事板图、AI 调整镜头卡提示词、编辑镜头卡文字信息、保存镜头卡修改、删除镜头卡、标记本镜头卡通过 |
| 镜头生成任务 | 暂停全部队列、重试全部失败任务、刷新任务状态 | 追加关键帧任务、追加视频任务、生成当前场任务、筛选任务状态 | 编辑任务参数、保存任务参数、重生成当前任务、删除当前任务、选为本镜头正式视频 |
| 镜头成片确认 | 返回生成任务、保存确认意见、确认本镜头进入拼接 | 检查当前镜头正式视频和前后镜头连续性 | 确认进入拼接、退回生成页修改、查看镜头卡 |

### 交互原则

1. 先选中要修改的对象，再输入修改要求。
2. 默认让创作者用自然语言描述意图，不强迫先写提示词。
3. 模型、输出类型、参考素材、影响范围放在面板内，作为可见但不喧宾夺主的设置。
4. 修改默认只作用于当前对象，例如当前分析模块、当前场、当前资产卡。
5. 修改后生成候选版本，创作者确认后才覆盖当前版本或保存为新版本。

### 页面对应关系

| 页面 | 修改对象 | 面板名称 | 默认范围 |
|---|---|---|---|
| 小说输入 | 当前章节 / 源内容解析结果 | AI 辅助修正源内容 | 当前章节 |
| AI 小说分析 | 故事梗概 / 人物关系 / 场景列表等模块 | AI 修改当前模块 | 当前模块 |
| 剧本化改写 | 第 N 集概览 / 第 N 场 | AI 修改当前场 | 当前场 |
| 资产卡管理 | 当前角色 / 场景 / 风格 / 道具 / 声音卡 | AI 生成/更新资产视觉图 | 当前选择的视觉资产 |

### 面板字段

- 修改要求：自然语言输入，例如“让台词更口语化”“场景更阴暗”“人物关系更清晰”。
- 模型：系统默认推荐，允许创作者切换。
- 修改范围：当前章节 / 当前模块 / 当前场 / 当前资产卡。
- 生成类型：文本改写、结构分析、图像参考、声音方向等。
- 参考素材：可引用上传素材或项目内已确认资产。

## 13. 页面 7：剧本化改写

剧本不是直接从原始小说盲生成，而是基于上一页已确认的故事梗概、剧情结构、人物关系、场景列表、道具线索和情绪曲线生成。创作者从 AI 小说分析页点击“确认全部分析，进入剧本改写”后，如果当前还没有剧本草案，系统自动生成分集/分场剧本；生成完成后进入审核编辑状态。

## 14. 页面 8：资产卡管理总览

### 页面目标

基于已确认剧本提取角色、场景、风格、道具、声音等资产草案，并让创作者逐类审核、编辑、补充参考和确认正式资产。

资产卡是分镜和生成前的稳定中间层。它不是简单素材库，而是把剧本中反复出现的人、地点、道具、视觉风格和声音规则固化下来，避免后续分镜、图像和视频生成出现角色漂移、场景不一致或风格跑偏。

资产草案必须从已确认剧本的全部分集和全部场次中提取，而不是只从当前场次提取。系统初始生成时应覆盖完整剧本，例如 8 集 46 场中的所有角色、主要场景、关键道具、全局风格和声音规则；创作者随后可以补充、合并、删除或拆分资产卡。

创作者从剧本化改写页确认剧本后进入资产卡管理页。如果当前剧本版本还没有资产草案，页面自动进入“AI 资产提取中”状态；提取完成后，才展示角色卡、场景卡、风格卡、道具卡和声音卡列表。

### 页面结构
```text
顶部：生成依据、资产提取状态、下一步入口
左侧：剧本范围树（全剧 / 集 / 场）+ 资产类型切换（角色 / 场景 / 风格 / 道具 / 声音）
中间：当前类型下的资产列表；点击某张资产后进入资产详情、字段、生成约束、参考图
右侧：确认清单、当前视觉资产生成/重生成、单卡信息编辑与确认
```

资产卡管理页左侧分为两块。上半部分是剧本范围树，用来说明资产草案覆盖全剧，并让创作者按“全剧 / 某一集 / 某一场”理解这些资产会在哪里被引用；下半部分是资产类型切换，用来切换角色、场景、风格、道具和声音。默认进入页面时选中“全剧资产草案”，因为角色、场景、道具等资产通常是跨多场复用的，不应默认误导为只属于某一个场次。

交互规则：点击“角色卡”先展示全部角色，例如 5 张角色卡；点击某个角色才打开内嵌角色详情。点击“场景卡”先展示全部场景，例如 6 张场景卡；点击某个场景才打开内嵌场景详情。风格卡、道具卡、声音卡同理。

资产卡管理必须支持创作者主动维护资产，而不是只能审核 AI 草案：
- 新增：可在当前资产类型下手动新增角色、场景、风格、道具或声音卡，新增卡默认为草案状态。
- 新增流程：点击新增后，系统先在当前类型列表中插入一张空白草案卡；创作者点击这张空卡进入详情，填写名称、设定、绑定关系、参考素材和生成要求后，再生成或完善资产卡。
- 编辑本卡信息：手动修改当前卡的名称、设定、关联场次、参考素材和生成约束，不直接改已生成图片。
- 保存本卡信息：提交并保存手动编辑后的卡片文字信息。
- 重生成当前视觉资产：创作者选择某一类视觉资产，修改参考图和结构化提示词后调用 gpt-image-2 重生成。该操作只更新当前选择的图片，不自动改文字字段。
- 从剧本补提当前类型：当创作者发现剧本里还有遗漏角色、场景、道具或声音时，触发 AI 只从已确认剧本中补充当前类型资产，不影响其他类型。
- 删除：未确认或未被下游引用的草案卡可删除；已确认并被分镜、镜头生成任务或结果引用的资产不直接物理删除，应先解除引用或归档，避免破坏后续一致性。
- 标记通过：表示当前卡已确认没有问题，可以作为分镜和后续生成的正式输入。
- 版本：新增、更新、AI 修改、删除/归档都应记录到资产版本或操作日志中，保存版本后再影响下游。

资产卡与场次/镜头是多对多关系，不是一张资产卡只绑定一个场次。以角色卡为例，主角“林澈”可能关联全片大多数场次；一个场次也会同时关联林澈、苏眠、旧城剧院、匿名信、冷雨霓虹风格等多张资产卡。场景卡、道具卡、声音卡同理；风格卡可以覆盖全片，也可以只覆盖回忆段落、某一集或某几个场次。

### AI 生成资产卡参数
- 基础字段：名称、来源、关联场次范围、状态。
- 生成要求：创作者输入的自然语言要求，例如外观、性格、空间结构、道具外形、声音方向或风格约束。
- 参考素材：上传图片、项目内已确认资产、剧本片段、场次引用或声音参考。
- 生成约束：正向提示词、负向提示词、不可变特征、禁止项。
- 模型：按资产类型选择图像、文本或声音模型；角色/场景/道具/风格图默认使用 gpt-image-2。
- 生成类型：人物图像、人物三视图、角色设定参考图、场景主图、场景俯视布局图、不同视角场景图、道具主图、道具多角度图、道具细节与使用场景图、风格参考、声音方向、结构化设定等。
- 影响范围：默认仅当前资产卡，不自动改同类型其他资产。

资产详情不再拆成独立页面，而是在资产卡管理页中内嵌完成。角色详情维护身份、外形、服装、动作、声音和生成约束；场景详情维护空间布局、光线、天气、不可变元素和生成约束；风格详情维护色彩、光影、构图、材质、参考图和正负向提示词。

资产卡的多图不是装饰，而是一致性约束。它的目的，是让后续分镜、关键帧、视频生成反复引用同一套视觉规则，减少人物漂移、场景空间错乱、道具外观变化和风格跑偏。

角色卡不是只有一张“卡片图”。以林澈角色卡为例，AI 初始生成时至少应生成三类一致性图：

- 人物图像：角色主形象，可是肖像、半身或全身，用于确认外观气质。
- 人物三视图：正面、侧面、背面，保持服装、发型、体态一致，用于后续镜头生成的一致性约束。
- 角色设定参考图：一张横版 character design sheet / character reference sheet / turnaround sheet，可包含角色信息卡、45 度脸部特写、三视图、服装变体、服装细节、习惯动作、经典表情等。

场景卡也需要类似的一致性图组。以旧城剧院场景卡为例，AI 初始生成时至少应生成：

- 场景主图：确认整体氛围、主视觉角度、色彩和光影。
- 场景俯视布局图：确认入口、舞台、观众席、放映室、红椅子、走廊等空间关系和关键物件位置。
- 不同视角场景图：确认入口视角、内部视角、反向视角、近景角落等，保证镜头从不同方向拍摄时空间仍然一致。

道具卡也需要一致性图组。关键道具会反复出现在特写、手持、桌面摆放、场景角落和剧情线索镜头里，如果只有一张参考图，后续很容易出现外形、比例、文字、材质和磨损痕迹不一致。以无署名信件或老式放映机为例，AI 初始生成时至少应生成：

- 道具主图：确认标准外观、材质、颜色、尺寸感和基础状态。
- 道具多角度图：正面、侧面、背面、开合状态、内部结构或可动部件，保证不同镜头角度下外观一致。
- 道具细节与使用场景图：手持比例、磨损、文字内容、纹理、机关、放置在场景中的尺度关系，用于特写和交互镜头。

这些视觉资产都不是“换模型”解决，核心输入是参考图 + 结构化提示词。创作者不满意时，应先选择具体视觉资产，例如人物图像、人物三视图、角色设定参考图、场景俯视布局图、不同视角场景图、道具多角度图或道具细节与使用场景图，再修改参考图、角色/场景/道具设定、排版要求、风格关键词和避免项，最后调用 gpt-image-2 重生成当前选择的图片。

角色设定参考图的提示词应明确它是“角色设定集 / character design sheet / character reference sheet / turnaround sheet”，并说明横版白底排版、三视图、服装变体、局部细节、动作表演、表情设定和文字策略。大量中文小字不要求完全准确；如果文字需要 100% 可读，应后期用设计工具叠加。

## 15. 页面 9：AI Storyboard

### 页面目标

将已确认剧本和已确认资产拆解为镜头级 Storyboard，生成可审核的镜头卡。创作者在这里确认每个镜头画什么、使用哪些角色/场景/道具/风格资产、景别机位运镜如何安排，以及镜头提示词是否可用于后续图像/视频生成。

AI Storyboard 不是生成视频，也不是继续写剧本。它是“剧本和资产”到“镜头生成任务”之间的可执行分镜层。确认后的镜头卡会成为后续关键帧、视频、配音和字幕生成的输入。

镜头卡不是最终视频，也不是单纯的一段文字。它是一张“故事板图片 + 结构化生成信息”的复合卡。每个镜头未来会生成一段短视频，例如 5 秒；故事板图片是用 gpt-image-2 基于参考图、镜头卡提示词、资产卡和剧本上下文生成的一张图片。注意：这里不是 9 张图片，而是一张图片；这张图片内部的版式可以是 9 宫格、12 格或其他分镜板排版，取决于提示词如何写。它用于让创作者直观看到这几秒镜头的构图变化、动作节奏、视线方向、镜头运动和画面方向。结构化生成信息用于把这张视觉图板落成可执行参数，描述这一小段画面要拍什么、用哪些资产、采用什么景别、机位和运镜，以及后续用于生成图片或视频的提示词。

故事板的核心用途，是在真正生成视频之前，把“每个镜头将来这几秒视频该怎么拍”先变成可审核的视觉计划。它不是只展示文字字段，也不是直接生成最终视频；它主要让创作者逐镜头确认 gpt-image-2 生成的故事板图片是否表达了正确的构图、动作、节奏和镜头运动，再确认旁边的文字、参数和提示词能否支撑后续生成。

镜头卡主要表达“这一小段画面在叙事里要完成什么”。它不是只表达画面好不好看，而是同时表达剧情目的、视觉内容、角色动作、情绪氛围和生成约束。例如“建立剧院入口氛围”“让林澈进入危险空间”“强调门把特写制造悬念”。

AI Storyboard 的输入不是视频，而是已确认剧本版本、已确认资产卡、项目画幅/时长策略和创作者补充要求。创作者进入 AI Storyboard 页面后，系统自动开始 AI 拆镜：先按小说的集、场次结构生成场次列表，再把每个场次拆成多个镜头；每个镜头自动生成一张镜头卡，镜头卡内包含故事板图片、故事板提示词、视频生成提示词和结构化生成信息。AI Storyboard 的产出不是最终视频，而是一组可审核、可修改、可进入生成任务的镜头卡。进入“镜头生成任务”页面后，系统才会基于这些镜头卡创建关键帧、视频、配音、字幕等任务。

一张镜头卡由以下内容组成：

| 组成 | 说明 |
|---|---|
| 故事板图片 | 当前镜头未来几秒视频的视觉拆解，是镜头卡的核心内容之一，不是最终成片；由 gpt-image-2 基于参考图和提示词生成的一张图片，图片内部可以排成 9 宫格、12 格等 |
| 画面任务 | 这个镜头要表达的剧情目的或视觉目的 |
| 画面描述 | 画面里出现什么、角色在做什么、环境是什么 |
| 景别 / 机位 / 运镜 | 远景、中景、特写、俯拍、跟拍、推入等镜头语言 |
| 绑定资产 | 使用哪些角色卡、场景卡、道具卡、风格卡 |
| 情绪与节奏 | 紧张、压抑、舒缓、悬疑、转折等 |
| 生成提示词 | 给图像/视频模型使用的正向提示词和负向提示词 |
| 生成参数 | 当前镜头进入生成任务前需要确认的画幅、时长、首尾帧、参考图、建议模型等 |
| 缩略图 | 9 宫格说明图在列表里的缩略预览 |

生成参数应该在当前选中的镜头卡右侧直接体现出来，而不是藏到下一页。创作者在 Storyboard 页面先确认“这个镜头是否值得生成、生成方向是否正确”；进入镜头生成任务页面后，再批量执行图片或视频生成。

右侧“AI 按要求调整镜头卡”修改的是当前镜头卡的生成依据，主要是故事板图提示词和结构化生成信息。它不是直接改已经通过的视频结果。可调整内容包括故事板图提示词、画面任务、画面描述、台词/旁白、音效/配乐、景别、机位、运镜、关联资产、情绪氛围、画幅、时长、建议模型、正向提示词和负向提示词。修改后可调用 gpt-image-2 重新生成故事板图片，并形成新的镜头卡版本。

大模型在 AI Storyboard 页的作用：

1. 根据已确认剧本和资产拆分镜头卡。
2. 为每张镜头卡生成画面任务、镜头语言、资产绑定和提示词。
3. 根据创作者的自然语言修改要求，局部重写当前镜头卡。
4. 基于参考图、镜头卡提示词、资产卡和剧本上下文调用 gpt-image-2 生成或刷新故事板图片，用于帮助创作者判断这几秒视频的画面推进是否正确。
5. 不直接生成最终图片或视频；最终生成发生在“镜头生成任务”页面。

### 页面布局
```text
顶部：生成依据、AI 拆镜状态、下一步入口
左侧：分镜目录（集 → 场 → 镜头卡），体现“第几集 / 第几场 / 当前有哪些镜头卡”
中间：当前场次的镜头卡列表 / 分镜板视图
右侧：当前镜头卡详情、绑定资产、提示词、AI 调整当前镜头卡
展开工作区：故事板图片预览、参考图、故事板提示词、图片规格、生成/重生成、保存到镜头卡
```

创作者从资产卡管理页确认资产后进入 AI Storyboard。如果当前剧本和资产版本还没有镜头卡，页面自动进入“AI 拆镜中”状态；系统自动完成以下任务后，才展示按分集和场次归类的镜头卡：

1. 按集和场次读取已确认剧本。
2. 为每个场次自动拆分镜头。
3. 为每个镜头生成结构化镜头卡。
4. 为每个镜头组装故事板提示词，并调用 gpt-image-2 生成一张故事板图片。
5. 为每个镜头生成后续视频任务需要的正向提示词、负向提示词、建议模型和生成参数。

页面状态分为两种：

1. AI 拆镜中：刚从资产卡进入，且当前剧本版本 + 资产版本还没有镜头卡草案。页面展示拆镜、故事板图生成和提示词生成进度，镜头卡列表暂不展示或展示骨架占位。
2. 审核镜头卡：AI 拆镜和故事板图生成完成后，页面展示分集概览、场次列表、镜头卡列表和右侧当前镜头卡详情。此时创作者开始确认、调整和保存版本。

交互层级：点击“第 1 集概览”查看本集分镜概况；点击“第 2 场：旧剧院后门”查看该场所有镜头卡；当前场在左侧展开 `SH-001、SH-002...` 镜头卡节点。点击左侧某张镜头卡或中间某张镜头卡，右侧都会同步切换到该镜头卡详情，展示故事板图片预览，并允许调整画面任务、故事板提示词、绑定资产、景别、运镜、画幅、时长和提示词。

中间镜头卡列表是当前场的工作区，用于批量浏览、切换视图、新增镜头卡和重新拆分当前场；左侧分镜目录是层级导航，用于让创作者始终知道自己处在第几集、第几场、第几个镜头卡。

不再单独设置“镜头详情页”。镜头卡详情直接内嵌在 AI Storyboard 右侧，避免创作者在“分镜”和“详情”之间来回跳转。确认后的镜头可以进入“镜头生成任务”，不要求全片分镜一次性全部通过。

生成门槛按范围分级：
- 单个镜头卡通过：可生成单个镜头。
- 当前场全部镜头卡通过：可生成当前场。
- 当前集全部场次通过：可生成当前集。
- 全部分镜通过：可批量生成全片。

### 镜头卡字段
| 字段 | 说明 |

| 镜头卡编号 | 如 S01-C03-SH005 |
| 所属集数 / 场次 | 用于排序和归类 |
| 故事板图片 | 当前镜头未来几秒视频的视觉推进图，由 gpt-image-2 根据参考图和故事板提示词生成；系统存储和展示的是一张图片，不是多张子图 |
| 故事板提示词 | 生成故事板图片的专用提示词，包含排版、画风、镜头格数、每格内容、中文标题/编号、运镜箭头和避免项 |

| 景别 | 远景 / 全景 / 中景 / 近景 / 特写，可调整 |

| 场景 | 绑定场景卡，可替换 |
| 道具 | 绑定道具卡，可增删 |
| 台词 / 旁白 | 来自剧本或人工编辑 |
| 音效 / 配乐 | 声音提示 |
| 镜头时长 | 秒 |
| 正向提示词 | 自动组合生成，可编辑 |
| 负向提示词 | 自动组合生成，可编辑 |
| 审核状态 | 待审核 / 已通过 / 需修改 |

### 视图模式
- 卡片视图
- 表格视图：只切换当前场镜头卡列表的展示方式，不改变镜头卡内容。
- 分镜板视图
- 时间线视图

### 操作按钮
- 新增镜头卡：在当前场的镜头卡列表中追加一张空白镜头卡，创作者选中后在右侧填写画面描述、镜头语言、关联资产、声音和提示词，也可以再让 AI 调整。
- AI 重新拆分当前场：只对当前选中的场重新生成镜头卡草案，不影响其他场；执行前需要保留当前版本。
- 编辑故事板提示词：修改提供给 gpt-image-2 的故事板生成提示词，例如排版、格数、画风、每格镜头内容、中文标题、运镜箭头、参考图权重和避免项。
- 重生成故事板图：使用当前参考图和故事板提示词重新调用 gpt-image-2，生成一张新的故事板图片。
- AI 调整镜头卡提示词：创作者用自然语言描述修改要求，由 AI 帮助重写故事板提示词和镜头卡结构化信息。它适合整体方向不满意，需要图示提示词、参数和视频生成提示词一起联动修改的情况；不直接改已经通过的视频结果。
- 编辑镜头卡文字信息：创作者直接修改当前镜头卡的结构化字段，包括画面任务、画面描述、台词/旁白、音效/配乐、景别、机位、运镜、关联资产、画幅、时长、模型、正向提示词和负向提示词。
- 保存镜头卡修改：提交当前镜头卡的修改，修改范围只影响当前镜头卡。
- 删除镜头卡：删除当前不需要的镜头卡，删除后回到当前场的镜头卡列表；已经进入生成或审核通过的镜头应先解除通过状态再删除。
- 标记本镜头卡通过：表示当前镜头卡内容、资产、参数和提示词已经可用于生成。
- 确认当前场进入生成：当前场镜头卡审核完成后，可将本场镜头卡批量送入镜头生成任务。
- 保存分镜版本：保存当前整套分镜草案，便于回退和版本对比。
- 全部分镜通过后，可批量生成全片

### 不满意时如何修改

创作者不是从空白创建镜头卡，而是在 AI 自动生成的结果上做审核和修正。常见修改路径如下：

- 故事板图片方向不对：先修改故事板提示词、参考图或排版/画风要求，再点击“重生成故事板图”。例如把“普通彩图”改成“黑白铅笔导演分镜稿、3 行 x 3 列、中文编号、彩色运镜箭头”。
- 故事板图片内容不对：修改每格内容描述、角色动作、镜头推进、景别顺序或参考资产，再重新生成故事板图。
- 镜头本身拆得不对：使用“AI 调整镜头卡提示词”描述修改要求，例如“这个镜头不要从远景开始，直接从信封特写开始，时长改为 3 秒”，系统联动更新故事板提示词、画面描述、运镜和视频生成提示词。
- 只是文字参数不对：使用“编辑镜头卡文字信息”，直接修改时长、景别、机位、运镜、台词/旁白、音效、关联资产、正向提示词和负向提示词。
- 当前镜头多余：删除镜头卡；删除后回到当前场镜头列表。
- 当前场拆镜整体不满意：使用“AI 重新拆分当前场”，只重拆当前场，不影响其他场次。
- 全局分镜方向不对：使用“重新拆分全部分镜”，重新生成全片镜头卡和故事板图，需要保存旧版本以便回退。

修改完成后，创作者保存镜头卡修改；确认故事板图片、结构化信息和提示词都可用于生成后，标记本镜头卡通过。

### 故事板图片生成工作区

右侧详情只展示故事板图片预览和入口，不承载完整生成配置。AI 自动生成结果不满意时，点击“编辑故事板提示词”或“重生成故事板图”后，页面展开故事板图片生成工作区：

- 左侧展示 gpt-image-2 生成的一张故事板图片预览，例如图片内部是 3 行 x 3 列的 9 宫格，或 3 行 x 4 列的 12 格故事板；页面不把它拆成 9 张或 12 张独立图片。
- 右侧配置生成输入：参考图、角色/场景/道具资产、故事板提示词、图片尺寸、画风、布局、避免项。
- 参考图可以是专业电影分镜故事板、角色卡、场景卡、道具卡或创作者上传图片。
- 故事板提示词应明确：这是 storyboard sheet / cinematic storyboard / director storyboard，不是真实照片、漫画彩页或 3D 渲染。
- 如果要求中文标题、编号和批注，需要提示模型保留中文信息感；小字批注不保证完全准确，必要时后期用编辑器叠加文字。
- 保存故事板图片后，当前镜头卡形成新版本；只有标记通过后，才进入镜头生成任务。

## 16. 页面 10：镜头生成任务

### 页面目标

以镜头为单位管理图像、视频、语音生成任务。这个页面承接的是 AI Storyboard 已审核通过的镜头卡，而不是重新拆镜；每个任务都应清楚展示它消费了哪张镜头卡、哪张故事板图、哪些资产一致性图组和哪些生成参数。它的核心产出是每个镜头的视频候选，创作者在这里围绕候选进行预览、完善、重生成、删除和送审。

### 页面结构
```text
左侧：生成目录（集 → 场 → 镜头 → 任务），展开当前镜头下的关键帧、视频候选、配音、字幕任务
中间：当前镜头任务列表 / 任务筛选 / 批量生成 / 批量重试
右侧：任务详情抽屉 / 视频候选工作区 / 当前任务修改与重生成
```

镜头生成任务页的左侧不再只是“镜头队列”。它应该体现任务来源链路：第几集、第几场、哪个已通过镜头卡，以及这个镜头下面有哪些生产任务。点击某个镜头时，中间显示该镜头的全部任务；点击左侧某个任务节点时，中间任务行和右侧详情同步切换。这样创作者能明确区分“当前镜头”和“当前任务”，也能看懂关键帧、视频候选、配音、字幕是同一个镜头下的不同生产任务。

### 表格字段
| 字段 | 说明 |
|---|---|
| 镜头编号 | 关联 Storyboard 镜头 |
| 任务类型 | 关键帧 / 视频 / 配音 / 字幕 |
| 输入方式 | 文生图 / 图生视频 / 首帧视频 / 首尾帧视频 |
| 模型 | 使用的模型供应商和模型名 |
| 状态 | 待生成 / 排队中 / 生成中 / 成功 / 失败 |
| 生成数量 | 候选版本数量 |
| 耗时 | 任务耗时 |
| 审核状态 | 待审核 / 通过 / 退回 |
| 操作 | 修改 / 重生成 / 审核 / 取消 / 删除 |

### 任务输入来源

镜头生成任务必须把输入来源放在任务详情区的显著位置，避免创作者误以为这里只是一个模型按钮队列：

- 来源镜头卡：当前任务所属镜头，例如 `SH-001 · 远景→中景`。
- 本镜头故事板图：AI Storyboard 中保存的故事板图片版本，例如 `SH-001 故事板图 V2`。
- 镜头提示词：由镜头卡结构化信息组装出的正向提示词、负向提示词和运动约束。
- 资产一致性图组：角色、场景、道具等通过资产卡确认的多图参考，例如角色图像、三视图、设定参考图、场景俯视图、不同视角图、道具多角度图。
- 生成参数：画幅、时长、候选数量、模型、首帧/尾帧、参考强度等。

关键帧任务、视频任务、配音任务和字幕任务都可以追加或删除，但都必须保留与镜头卡、故事板图和资产版本的追溯关系。

### 视频候选工作区

当选中视频任务时，右侧不应只是展示任务参数，而应变成“视频候选工作区”。创作者最关心的是当前镜头已经生成了哪些候选、哪个最好、能不能基于某个候选继续改。

候选工作区应包含：

- 视频预览：播放当前候选，支持切换 A/B/C 候选。
- 候选列表：显示模型、生成状态、生成时间、差异标签和当前审核状态。
- 选为正式视频：把当前候选设为本镜头的正式视频，后续只把这个正式视频传入镜头成片确认页。
- 基于本版重生成：保留当前候选的构图、角色一致性或首帧，修改提示词/参数后生成新候选。
- 局部微调：用自然语言描述小范围修改，例如“雨水反射更强、推镜慢一点、不改变服装和脸”。
- 删除候选：删除未送审、未通过的候选；已送审或已通过的候选应改为归档或先取消通过，避免破坏追溯。
- 追加视频候选：同一镜头允许继续生成新的候选，而不是覆盖旧候选。

从体验上，视频候选不应该只有“重生成当前任务”。更合理的是把操作拆成三类：

| 操作类型 | 创作者意图 | 推荐按钮 |
|---|---|---|
| 选择 | 这个候选不错，准备作为本镜头视频 | 预览、选为正式视频 |
| 完善 | 大方向对，只想微调 | 局部微调、基于本版重生成 |
| 清理 | 这个候选不需要 | 删除候选 / 归档候选 |

### 镜头级任务操作
- 每个镜头下可追加关键帧、视频、配音、字幕等任务，不要求只能由整场批量创建。
- 每个任务支持修改生成参数后重生成；关键帧不满意时可改提示词、参考图、模型或候选数量后重新生成。
- 追加出来的任务支持删除；已确认通过的正式结果不直接删除，应先取消通过或归档版本，避免误删成片素材。
- 视频生成以镜头为单位发起：选中镜头后点击“生成视频”或“追加视频候选”，可为同一镜头保留多个视频候选版本。

### 任务详情
- 输入提示词
- 参考图 / 参考视频
- 模型参数
- 输出结果
- 错误信息
- 审核意见
- 输入来源追溯：镜头卡版本、故事板图版本、资产一致性图组版本

## 17. 页面 11：镜头成片确认

### 页面目标

确认镜头生成任务页选出的“本镜头正式视频”是否可以进入后期拼接。这个页面不再承担生成候选和挑选候选的工作；候选选择发生在镜头生成任务页。这里主要检查正式视频是否符合镜头卡、故事板图、资产一致性要求，以及首尾帧能否和前后镜头顺利衔接。

### 页面布局
```text
左侧：确认目录（集 → 场 → 正式镜头），展示已确认、待确认、待生成状态
中间：上一镜头 / 当前镜头正式视频 / 下一镜头的连续性检查
右侧：确认意见、退回修改、进入后期拼接
```

镜头成片确认页的左侧目录承接镜头生成任务页已选出的“正式视频”，不是视频候选列表。目录层级为“集 → 场 → 正式镜头”，每个镜头节点展示是否已确认、待确认、待生成或已进入拼接。点击某个正式镜头后，中间显示上一镜头、当前正式视频和下一镜头，用来检查首尾帧、角色场景一致性和镜头衔接。

这里不再让创作者在多个视频候选中选择一个；选择候选发生在镜头生成任务页。确认页只判断“当前正式视频能不能进入后期拼接”。如果不通过，退回镜头生成任务页重新选择候选、局部微调或重生成。

### 结果卡片字段
- 镜头编号
- 正式视频版本
- 缩略图 / 视频播放器
- 时长和画幅
- 首帧 / 尾帧
- 对应镜头卡版本
- 对应故事板图版本
- 对应资产一致性图组版本
- 确认状态
- 退回原因

### 确认依据

镜头成片确认页需要展示以下依据：

- 镜头卡：画面任务、画面描述、景别、机位、运镜、时长、台词/旁白和音效要求。
- 故事板图：用于判断构图推进、动作节奏、视线方向和镜头运动是否符合 Storyboard。
- 资产一致性图组：用于检查角色脸、服装、场景空间、道具外形、比例、材质和关键标记是否稳定。
- 生成参数：用于判断画幅、时长、候选数量、模型和首帧/尾帧策略是否正确。
- 前后镜头：检查当前镜头首尾帧是否能承接上一个镜头，并自然进入下一个镜头。

确认意见应说明当前正式视频是否可进入拼接；如果不通过，应退回镜头生成任务页继续重生成、局部微调或重新选择正式视频。

### 操作按钮
- 确认进入拼接
- 退回生成页修改
- 查看镜头卡
- 查看故事板图
- 保存确认意见

## 18. 页面 12：后期预览与导出

### 页面目标

将已确认的正式镜头视频按集、场、镜头顺序自动拼接成可预览的成片时间线，并在此基础上管理字幕、配音、BGM、音效和导出版本。

### 页面布局
```text
左侧：剪辑目录（集 → 场 → 已确认正式镜头片段）
中间：视频预览播放器 + 视频 / 字幕 / 配音 / BGM / 音效轨道
右侧：导出设置 / 版本记录
```

后期预览与导出页承接镜头成片确认页已经进入拼接的正式镜头。左侧剪辑目录不展示候选视频，也不展示未确认镜头；它展示的是已经进入时间线的正式镜头片段，以及仍在等待拼接或音频检查的片段状态。创作者点击某个片段时，中间播放器定位到该时间段，轨道区同步展示视频、字幕、配音和音效是否对齐。

拼接规则默认按“集 → 场 → 镜头编号”自动排序。创作者可以保存预览版本，之后再创建导出任务。导出任务产出 MP4 或其他格式的成片文件，并记录来源镜头、字幕版本、配音版本、BGM/音效版本和导出参数。

### 功能模块
1. 视频片段拼接。
2. 字幕生成和编辑。
3. 配音生成和替换。
4. BGM / 音效素材管理。
5. 预览版本保存。
6. 成片导出。

### 导出设置
- 分辨率
- 画幅
- 帧率
- 字幕开关
- 音频开关
- 导出格式

- 资产卡生成任务
- Storyboard 生成任务
- 图像生成任务
- 视频生成任务
- 语音生成任务

- 待执行
- 排队中
- 执行中
- 成功

### 页面结构

```text
左侧：任务范围（全部、失败待处理、视频队列、运行中、排队中、高成本任务）
中间：任务总览指标、组合筛选、任务列表、任务详情
右侧：任务详情/排障/重试/队列策略抽屉
```

### 总览指标

- 项目
- 状态

- 模型供应商

### 列表字段

| 字段 | 说明 |
|---|---|
| 任务 | 任务名称、任务 ID、来源链路 |
| 项目 | 所属项目、负责人 |
| 类型 | 文本 / 图像 / 视频 / 语音 / 导出等 |
| 模型 | 供应商和模型名 |
| 状态 | 待执行 / 排队中 / 执行中 / 成功 / 失败 / 已取消 |
| 进度 | 百分比、已耗时、预计剩余时间 |
| 成本 | 当前消耗、预估成本 |
| 重试 | 重试次数和失败保护状态 |

### 任务详情

- 输入来源：项目、版本、集、场、镜头、资产、参考素材。
- 请求参数：模型、尺寸、时长、候选数量、提示词、负向提示词、种子、优先级。
- 运行状态：排队时间、开始时间、耗时、预计剩余时间、结果数量。
- 错误摘要：失败原因分类、供应商错误码、可重试性判断。
- 运行日志：调度日志、供应商回调、素材拉取、结果写入。
- 产物入口：生成结果、资产卡、正式镜头、导出文件。

### 操作

- 查看详情
- 取消任务
- 复制任务参数
- 查看日志和错误原因
- 调整参数并重试
- 按失败原因批量重试
- 暂停 / 恢复某类队列
- 调整任务优先级

### 失败处理原则

- 失败任务不能只提供“重试”，必须先展示错误原因和处理建议。
- 对同一错误连续失败的任务应触发失败保护，避免无限重试消耗额度。
- 批量重试必须按失败原因分组，只对可重试分组执行。
- 参考素材不可访问、参数非法、额度不足等错误应提示对应责任方和修复入口。

## 28. 原型交互重点

1. 每个 AI 生成结果都必须有“编辑、重新生成、保存版本、确认”四类操作。
2. 下游流程只能读取已确认版本。
3. Storyboard 镜头必须能绑定角色卡、场景卡和风格卡。
4. 镜头生成任务必须展示提示词、参考图、模型参数和结果版本。
5. 镜头成片确认必须支持正式镜头检查、前后镜头连续性检查和退回生成页修改。
6. 资产库必须能追溯资产来源、使用镜头和审核记录。
7. 页面上要明确区分“AI 生成内容”和“人工确认内容”。
