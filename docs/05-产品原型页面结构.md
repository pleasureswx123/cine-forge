# AI 内容工业化平台｜产品原型页面结构

> 适用范围：第一阶段核心闭环原型。  
> 原型目标：让产品、设计、研发、老板能清楚看到“用户如何从小说文本一路生产到视频片段和成片预览”。  
> 建议工具：Figma / Axure / 墨刀 / MasterGo。  

---

## 1. 原型设计目标

第一阶段原型不追求覆盖完整大平台，而是重点表达一条可落地的生产闭环：

```text
项目创建
  ↓
小说文本输入
  ↓
AI 小说分析
  ↓
剧本化改写
  ↓
角色卡 / 场景卡 / 风格卡
  ↓
AI Storyboard
  ↓
镜头级生成任务
  ↓
关键帧 / 视频片段审核
  ↓
简单成片预览
  ↓
项目资产沉淀
```

原型重点展示：

1. 用户从哪里开始。
2. 每一步 AI 生成什么。
3. 人工在哪里确认、修改、重生成。
4. 资产如何被后续环节复用。
5. 镜头如何进入图像/视频生成任务。
6. 项目最终如何形成预览和资产库。

## 3. 一级导航结构

| 一级导航 | 说明 | 第一阶段优先级 |
|---|---|---|
| 工作台首页 | 展示项目总览、待办、最近任务、成本概览 | P1 |
| 项目管理 | 创建项目、查看项目列表和项目状态 | P0 |
| 生产工作台 | 单个项目的核心生产流程页面 | P0 |
| 资产库 | 查看项目内沉淀的角色、场景、风格、镜头、媒体文件 | P0 |

| 系统设置 | 用户、权限、提示词模板、基础配置 | P2 |

第一阶段建议将“生产工作台”作为最核心页面，其他页面围绕它展开。

## 6. 页面 1：工作台首页

### 页面目标

让管理者和项目成员快速看到平台整体生产状态。

### 页面模块

1. 数据概览卡片：项目总数、进行中项目、待审核任务、今日生成任务、模型成本。
2. 最近项目：项目名称、类型、状态、负责人、更新时间、进度。
3. 我的待办：待确认剧本、待审核资产卡、待审核视频片段。
4. 任务状态：排队中、生成中、失败、已完成。
5. 快捷入口：创建项目、导入小说、查看任务中心。

### 关键操作

- 创建项目
- 进入项目工作台
- 查看待审核任务
- 查看失败任务

## 8. 页面 3：创建项目

### 页面目标

建立项目基础信息，作为后续流程容器。

### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| 项目名称 | 文本 | 是 | 内容项目名称 |
| 项目类型 | 下拉 | 是 | 短剧 / 漫剧 / 动漫 / 影视 |
| 题材类型 | 多选 | 否 | 都市、古装、玄幻、悬疑等 |
| 目标时长 | 数字 | 否 | 预计成片时长 |
| 目标集数 | 数字 | 否 | 短剧/漫剧集数 |
| 画幅比例 | 单选 | 是 | 16:9 / 9:16 / 1:1 |
| 语言 | 下拉 | 是 | 中文 / 英文等 |
| 初始风格方向 | 文本 | 否 | 例如赛博朋克、国风、水彩等 |
| 备注 | 文本域 | 否 | 项目说明 |

### 操作按钮

- 保存草稿
- 创建并进入小说输入

## 9. 页面 4：项目概览

### 页面目标

展示单个项目的生产状态和核心资产。

### 页面模块
1. 项目信息卡：名称、类型、题材、负责人、当前阶段、创建时间。
2. 生产流程进度条：小说输入、分析、剧本、资产、Storyboard、生成、后期。
3. 关键统计：角色数、场景数、镜头数、已生成视频数、待审核数、累计成本。
4. 最近版本：分析版本、剧本版本、Storyboard 版本、预览版本。
5. 快捷操作：继续生产、查看任务、进入资产库、生成预览。

## 10. 页面 5：小说输入

### 页面目标

录入或上传小说文本，作为 AI 分析输入。

### 页面布局
```text
左侧：章节列表
中间：文本编辑器
右侧：输入设置 / AI 分析按钮 / 历史版本
```

### 功能模块
1. 小说文本录入：支持粘贴正文。
2. 文件上传：支持 TXT / DOCX / Markdown。
3. 章节管理：新增章节、删除章节、调整顺序。
4. 文本统计：字数、章节数、预计分析耗时。
5. 分析设置：分析范围、目标类型、输出粒度。
6. 发起 AI 分析。

### 操作按钮
- 保存文本
- 新增章节
- 上传文件
- 发起 AI 小说分析

## 11. 页面 6：AI 小说分析

### Tab 结构
1. 故事梗概
2. 剧情结构
3. 人物关系
4. 场景列表
5. 道具列表
6. 情绪曲线
7. 版本记录

### 核心字段
| 模块 | 字段 |
|---|---|
| 故事梗概 | 主题、核心冲突、主线剧情、结局方向 |

| 场景列表 | 场景名称、空间类型、出现章节、剧情作用 |

### 操作按钮
- 编辑当前结果
- 重新生成
- 保存为新版本
- 确认分析结果
- 进入剧本化改写

## 20. 页面 15：生成结果审核

### 页面目标

对同一镜头的多个生成版本进行对比和确认。

### 页面布局
```text
左侧：镜头信息和要求
中间：多版本结果对比
右侧：审核意见和操作
```

### 结果卡片字段
- 版本号
- 缩略图 / 视频播放器
- 模型名称
- 生成时间
- 生成参数
- 成本

## 26. 核心状态流转

### 26.1 项目状态
```text
草稿
  → 小说已输入
  → 小说分析中
  → 小说分析待确认
  → 剧本生成中
  → 剧本待确认
  → 资产生成中
  → 资产待确认
  → Storyboard 生成中
  → Storyboard 待确认
  → 镜头生成中
  → 生成结果待审核
  → 后期预览中
  → 已完成
```

### 26.2 审核状态
```text
待审核 → 已通过
待审核 → 需修改 → 重新提交 → 已通过
待审核 → 已退回
待审核 → 已废弃
```

```text
待生成 → 排队中 → 生成中 → 成功 → 待审核
待生成 → 排队中 → 生成中 → 失败 → 重试 / 取消
```

## 28. 原型交互重点

1. 每个 AI 生成结果都必须有“编辑、重新生成、保存版本、确认”四类操作。
2. 下游流程只能读取已确认版本。
3. Storyboard 镜头必须能绑定角色卡、场景卡和风格卡。
4. 镜头生成任务必须展示提示词、参考图、模型参数和结果版本。
5. 生成结果审核必须支持多版本对比和通过版本选择。
6. 资产库必须能追溯资产来源、使用镜头和审核记录。
7. 页面上要明确区分“AI 生成内容”和“人工确认内容”。

## 30. 原型演示脚本建议

11. 对比多个视频版本，选择一个通过。
12. 将通过镜头拼接成简单预览。
