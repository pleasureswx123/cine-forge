## 2. E01 工程基础与环境
### BE-001 初始化后端工程
- 优先级：P0
- 负责人：后端
- 内容：创建后端项目、路由结构、配置管理、日志、错误处理中间件。
- 验收：本地可启动，健康检查接口返回正常。

### FE-001 初始化前端工程
- 优先级：P0
- 负责人：前端
- 内容：创建前端项目、路由、布局、状态管理、请求封装、主题样式。
- 验收：可访问首页、项目列表占位页。

### OPS-001 Docker Compose 开发环境
- 优先级：P0
- 负责人：DevOps/后端
- 内容：PostgreSQL、Redis、MinIO、API、Worker 本地编排。
- 验收：一条命令可启动开发环境。

### BE-002 统一响应与异常处理
- 优先级：P0
- 内容：实现统一响应格式、错误码、请求 ID、参数校验错误处理。
- 验收：所有 API 错误返回统一结构。

## 3. E02 数据库与基础模型
### DB-001 创建数据库迁移框架
- 优先级：P0
- 内容：引入迁移工具，建立基础 migration 目录和执行命令。
- 验收：可执行建表和回滚。

### DB-002 创建用户、项目、成员表
- 优先级：P0
- 表：users、projects、project_members。
- 验收：项目 CRUD API 可读写。

### DB-003 创建小说与版本表
- 优先级：P0
- 表：novel_documents、novel_chapters、analysis_versions、script_versions。
- 验收：小说、分析、剧本可保存版本。

### DB-004 创建资产卡表
- 优先级：P0
- 表：character_cards、scene_cards、style_cards、prop_cards、voice_cards。
- 验收：资产卡可创建、编辑、确认。

### DB-005 创建镜头、任务、结果、审核表
- 优先级：P0
- 表：storyboard_shots、shot_asset_bindings、generation_tasks、generation_results、review_records。
- 验收：镜头和生成任务可闭环。

### DB-006 创建媒体、模型和提示词基础表
- 优先级：P0
- 表：media_assets、model_providers、model_invocations、prompt_templates。
- 验收：媒体文件可入库；P0 AI 任务可读取模型配置和提示词模板；模型调用可记录基础日志。

### DB-007 创建成本和导出表
- 优先级：P1
- 表：cost_records、export_versions。
- 验收：模型成本可统计，预览导出版本可追溯。

## 5. E04 AI 小说分析
### AI-201 小说分析 Prompt 模板
- 优先级：P0
- 内容：设计输出故事梗概、剧情结构、人物关系、场景、道具、情绪曲线的 Prompt。
- 验收：输出 JSON 能通过 Schema 校验。

### BE-201 文本模型适配器
- 优先级：P0
- 内容：统一封装 text.generate、结构化输出、超时、重试、错误记录。
- 验收：可通过配置调用至少一个文本模型。

### BE-202 小说分析任务 Worker
- 优先级：P0
- 内容：从任务队列消费，调用文本模型，写入 analysis_versions。
- 验收：任务状态从 queued → running → succeeded，失败可记录错误。

### BE-203 分析版本 API
- 优先级：P0
- 接口：列表、详情、编辑、确认、重新生成。
- 验收：确认后更新项目 currentAnalysisVersionId。

### FE-201 AI 小说分析页
- 优先级：P0
- 内容：故事梗概、剧情结构、人物关系、场景、道具、情绪曲线 Tab。
- 验收：可编辑、保存版本、确认分析结果。

### BE-302 剧本版本 API
- 优先级：P0
- 接口：列表、详情、编辑、确认、对比。
- 验收：确认后更新项目 currentScriptVersionId。

### FE-301 剧本编辑页
- 优先级：P0
- 内容：剧本结构树、编辑器、版本列表、确认按钮。
- 验收：用户可修改分场剧本并保存。

## 8. E07 AI Storyboard
### AI-501 Storyboard Prompt 模板
- 优先级：P0
- 内容：从确认剧本生成镜头卡，包括景别、机位、运镜、时长、提示词。
- 验收：输出镜头数组并可入库。

### BE-501 Storyboard 生成 Worker
- 优先级：P0
- 内容：生成 storyboard_shots，自动绑定候选角色/场景/风格。
- 验收：可从剧本生成镜头列表。

### BE-502 镜头 API
- 优先级：P0
- 接口：镜头列表、详情、创建、更新、确认、批量确认、提示词重生成。
- 验收：镜头支持资产绑定和排序。

### FE-501 Storyboard 页面
- 优先级：P0
- 内容：场次筛选、镜头卡列表、表格视图、生成按钮。
- 验收：可展示 AI 生成的镜头卡。

### FE-502 Storyboard 右侧镜头卡详情面板
- 优先级：P0
- 内容：当前镜头卡字段、参考图、资产绑定、提示词、生成参数、确认按钮。
- 验收：可在 Storyboard 页内编辑当前镜头卡，并进入镜头生成任务。

## 9. E08 镜头生成任务
### BE-601 任务队列基础能力
- 优先级：P0
- 内容：Redis 队列、任务状态、重试、取消、日志。
- 验收：支持异步执行和状态轮询。

### AI-601 图像模型适配器
- 优先级：P0
- 内容：统一 image.generate，支持 prompt、negativePrompt、referenceImages、count、尺寸。
- 验收：至少可返回图片 URL 或文件。

### AI-602 视频模型适配器
- 优先级：P0
- 内容：统一 video.generate，支持 text_to_video、image_to_video、first_frame_to_video。
- 验收：至少支持一种视频生成方式。

### BE-602 生成任务 API
- 优先级：P0
- 接口：创建单镜头任务、批量任务、任务列表、详情、重试、取消。
- 验收：任务结果写入 generation_results。

### BE-603 生成结果审核 API
- 优先级：P0
- 接口：审核结果、设置通过版本、查看审核记录。
- 验收：同一镜头可设置一个通过版本。

### FE-601 镜头生成任务页
- 优先级：P0
- 内容：任务表格、状态、模型、成本、操作。
- 验收：可查看任务执行状态。

### FE-602 生成结果审核页
- 优先级：P0
- 内容：多版本图片/视频对比、审核意见、通过/退回/重生成。
- 验收：可确认生成结果。

## 15. Definition of Done
每个任务完成必须满足：

1. 代码已提交到对应分支。
2. 接口或页面符合文档约定。
3. 关键路径有基本测试或手工验证记录。
4. 错误状态可见，不出现静默失败。
5. 重要操作有日志。
6. 涉及 AI 生成的任务必须记录 Prompt、参数、模型和耗时。
7. 涉及媒体文件的任务必须保存到对象存储并入库。
8. 涉及审核的任务必须写入 review_records。
