# AI 内容工业化平台｜第一阶段研发排期表

> 阶段目标：完成“小说文本 → AI 分析 → 剧本改写 → 资产卡 → Storyboard → 镜头生成 → 审核 → 简单预览”的核心闭环。  
> 推荐周期：10 周标准版，可压缩至 8 周或扩展至 12 周。  
> 推荐团队：产品 1、前端 1-2、后端 1-2、AI/模型 1、测试 1、设计/美术顾问 1、内容/编剧顾问 1。

---

## 1. 阶段目标

第一阶段交付一个可演示、可验证、可继续扩展的 MVP 原型系统，验证以下问题：

1. 小说文本是否能稳定拆解为结构化内容。
2. AI 剧本中间稿是否能编辑、确认、保存版本。
3. 角色卡、场景卡、风格卡是否能约束后续生成。
4. Storyboard 是否能承接剧本到视频生成之间的镜头设计。
5. 镜头级图像/视频生成是否能被任务化、版本化、审核化管理。
6. 项目资产是否能沉淀到资产库。

## 8. 里程碑验收标准

### M1：基础框架验收（第 2 周末）
- 可创建项目。
- 可输入小说文本。
- 可管理章节。
- 项目概览能展示流程状态。

### M2：文本智能验收（第 4 周末）
- 可发起 AI 小说分析。
- 可编辑并确认分析版本。
- 可生成剧本中间稿。
- 可编辑并确认剧本版本。

### M3：资产与分镜验收（第 6 周末）
- 可生成角色卡、场景卡、风格卡。
- 可编辑、上传参考资产并确认资产卡。
- 可生成 Storyboard 镜头卡。
- 镜头能绑定角色、场景、风格资产。

### M4：生成闭环验收（第 8 周末）
- 可生成关键帧/参考图。
- 可生成视频片段。
- 可查看多版本结果。
- 可审核通过某个生成结果。

### M5：项目演示验收（第 10 周末）
- 可将通过镜头拼接成简单预览。
- 可查看项目资产库。
- 可展示模型调用和成本记录。
- 可完整演示从小说到视频片段的核心闭环。

## 10. 主要风险与缓冲

| 风险 | 影响 | 缓冲策略 |
|---|---|---|
| 模型 API 不稳定 | 影响分析/生成闭环 | 准备 mock 模式和备用模型 |
| 视频生成耗时长 | 影响演示效率 | 先用少量镜头验证，任务异步化 |
| 结构化输出不稳定 | 影响后续流程 | JSON Schema 校验和重试 |
| 前端页面过多 | 影响周期 | 优先 12 个核心页面 |
| 文件处理复杂 | 影响图像/视频预览 | 第一阶段只做基础上传、预览和下载 |
| 资产字段过细 | 影响录入体验 | 先支持核心字段，扩展字段放 JSONB |

---

## 11. 第一阶段不建议做的事项

1. 完整复杂权限系统。
2. 多团队组织架构。
3. 大规模资产市场。
4. 商业级专业剪辑能力。
5. 自动化全流程无人审核。
6. 复杂 Agent 自主规划。
7. 高精度角色一致性检测算法。
8. 多租户私有化交付。

## 12. 最终验收演示路径

```text
创建项目
  → 输入小说文本
  → 发起 AI 小说分析
  → 编辑并确认故事梗概/人物/场景
  → 生成剧本
  → 编辑并确认剧本
  → 生成角色卡/场景卡/风格卡
  → 确认资产卡
  → 生成 Storyboard
  → 打开镜头详情并查看提示词
  → 生成关键帧
  → 生成视频片段
  → 对比多版本并审核通过
  → 拼接简单预览
  → 查看项目资产库
```
