# UI Mockups

本目录存放 AI 内容工业化平台第一阶段关键节点 UI 图。

## 文件

| 文件 | 说明 |
|---|---|
| `ai-content-platform-ui-board.html` | 可在浏览器打开的高保真 UI 画板 |
| `ai-content-platform-ui-board.png` | 从 HTML 渲染导出的完整长图 |

## 覆盖页面

1. 工作台首页
2. 项目管理
3. 创建项目
4. 项目概览
5. 小说输入
6. 项目画像确认
7. AI 小说分析
8. 剧本化改写
9. 资产卡管理
10. AI Storyboard
11. 镜头生成任务
12. 生成结果审核
13. 后期预览与导出
14. 项目资产库
15. 全局任务中心
16. 模型配置与成本
17. 提示词模板
18. 系统设置 / 访问控制

## 设计方向

- 单一创作者主导，而不是按传统岗位拆分。
- 以生产流程、AI 节点、版本确认、资产沉淀为核心。
- 后台产品风格，信息密度较高，适合后续直接拆成前端页面。
- 最左侧为统一全局导航；生产工作台内部左侧为项目流程导航，右侧为当前节点主工作区。
