AI 内容工业化平台关键节点 UI 图

定位为创作者主导的 AI 原生生产工作台。界面不按传统岗位拆分，而是围绕“项目流程、AI 节点、版本确认、资产沉淀、镜头级生成”组织，优先服务一个人高效完成动画/短剧/漫剧生产闭环。

单一创作者工作台 AI 节点驱动 镜头级生产 版本确认 资产复用
密度优先后台产品要可扫描、可操作，不做营销式大留白。
流程可见任何页面都能知道当前处于哪个生产节点。
AI 可控突出版本、提示词、参数、审核和重生成。
视觉有素材感图片、视频、分镜和资产区域要有真实生产感。
