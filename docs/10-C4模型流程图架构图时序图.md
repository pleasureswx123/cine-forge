```mermaid
        Component(video, "Video Adapter", "Adapter", "文生视频、图生视频、首帧/首尾帧视频")
```

## 14. 时序图：AI 小说分析

```mermaid
sequenceDiagram
    autonumber
    actor User as 内容创作者
    participant Web as Web 前端
    participant API as API 服务
    participant Queue as Redis Queue
    participant Worker as Worker
    participant Adapter as 模型适配层
    participant LLM as 文本大模型
    participant DB as PostgreSQL

    User->>Web: 点击“发起 AI 小说分析”
    Web->>API: POST /projects/{id}/analysis-tasks
    API->>DB: 创建 generation_tasks(task_type=novel_analysis, status=pending)
    API->>Queue: 投递分析任务
    API->>DB: 更新项目状态 analysis_running
    API-->>Web: 返回 taskId

    Worker->>Queue: 消费分析任务
```
